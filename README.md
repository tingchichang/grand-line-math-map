# 偉大航道學力航海圖

國中數學 111–115 年國中教育會考 × 學習扶助科技化評量（篩選測驗、成長測驗）同屆對照與教學轉化網頁。

- 同一屆學生的會考題目與七、八年級學扶測驗相同學習內容的對照總表
- 會考與篩選測驗題目、通過率、選項作答比例與誘答分析
- 學扶施測後回饋訊息、溯源重構五步法、BUCK 讀題策略示範
- 學力品質監控資料解讀摘要與會考前找學習斷點的作法

資料來源：心測中心會考數學科試題分析、學習扶助測驗回饋訊息與篩選測驗考古題、全國篩選測驗各題作答比例、輔導團講義與相關研習簡報。

網頁為單一檔案 `index.html`，直接以瀏覽器開啟即可。

## 學生闖關遊戲

`equation-game/index.html`：一元一次方程式闖關島。七座島對應七個學習重點（列式、分配律、等量公理天平、代入檢驗、解方程式、BUCK 讀題、魔王島真題），練習題隨機產生，真題取自會考與學習扶助篩選測驗，並顯示全國作答比例。
